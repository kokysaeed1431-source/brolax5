📜 محرر السكربت البرمجي

اكتب كود جافا سكربت يُنفّذ داخل اللعبة. الكود يُحفظ مع الماب ويُشغّل تلقائياً. استخدم الدوال الجاهزة للتحكم بالعناصر واللاعب.
📊 API المتاحة:
• onTick(dt) — كل إطار
• onStart() — عند بدء اللعبة
• log(msg) — طباعة في المخرجات
• getPlayer() — بيانات اللاعب
• getBlocks() — كل العناصر
• findBlock(name) — عنصر بالاسم
• moveBlock(b, x,y,z)
• scaleBlock(b, sx,sy,sz)
• rotateBlock(b, rx,ry,rz)
• giveCoins(n) — عملات للاعب
• showMessage(t) — رسالة على الشاشة
